# Employee Management System

A full-stack Employee Management System built with Angular 24, ASP.NET Core 8 Web API, SQL Server, Entity Framework Core, and JWT Authentication.

## 🚀 Features

- Employee Management
- Payroll Management
- Leave Management
- Role-Based Access Control
- Profile Management
- Dashboard Analytics
- JWT Authentication
- Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- Angular 24
- TypeScript
- HTML
- CSS

### Backend
- ASP.NET Core 8
- Web API
- C#

### Database
- SQL Server
- Entity Framework Core

### Authentication & Security
- JWT Authentication
- Role-Based Access Control
